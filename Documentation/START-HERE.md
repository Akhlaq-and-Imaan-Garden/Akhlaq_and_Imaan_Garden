## 🆘 Need Help?

### **Common Questions:**

**Q: Do I need a server?**
A: No! This is a static website. Just open index.html.

**Q: Do I need app icons?**
A: No, but recommended. App works with default icons.

**Q: How do I change the Ramadan date?**
A: Edit `js/app.js` line 14 and `service-worker.js` line 204.

**Q: Can I customize the quests?**
A: Yes! Edit `js/quests-data.js` - all content is there.

**Q: How do I deploy this?**
A: Easiest: Drag to netlify.com. Or use any web host.

**Q: Does it work offline?**
A: Yes! After first load, works completely offline.

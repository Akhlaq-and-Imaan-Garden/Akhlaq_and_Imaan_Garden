🌙 RAMADAN QUESTS - QUICK START
================================

⚡ FASTEST WAY TO USE:
----------------------
1. Open index.html in your browser
2. That's it! Everything works immediately.

📱 TO TEST PWA FEATURES:
-----------------------
1. python -m http.server 8000
2. Open http://localhost:8000
3. Test installation and offline mode

🌐 TO DEPLOY ONLINE:
-------------------
Option 1: Netlify (easiest)
  - Go to netlify.com
  - Drag and drop project folder
  - Done! Your app is live.

Option 2: Vercel
  - Go to vercel.com
  - Connect GitHub repository
  - Automatic deployment

Option 3: GitHub Pages
  - Push to GitHub
  - Settings → Pages
  - Select branch → Save

Option 4: Any Web Host
  - Upload all files
  - No server needed (static site)

📝 IMPORTANT: SET RAMADAN DATE
------------------------------
Edit js/app.js line 14:
  const ramadanStartDate = new Date('2025-02-28');

Also edit service-worker.js line 204 (same date)

Ramadan 2025 starts: February 28, 2025 (approx)

🎨 TO CUSTOMIZE:
---------------
Colors: css/style.css (lines 9-12)
Quests: js/quests-data.js (all quest content)

🔧 TROUBLESHOOTING:
------------------
Problem: Countdown shows wrong time
Fix: Update ramadanStartDate in js/app.js

Problem: PWA won't install
Fix: Use HTTPS or localhost (not file://)

Problem: Progress not saving
Fix: Enable LocalStorage in browser

Problem: Icons missing
Fix: Normal! Add icons or ignore (optional)
